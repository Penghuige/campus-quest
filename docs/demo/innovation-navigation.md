## 约五分钟的验收

1. 用 **20269003** 登录。桌面主导航点击“创新创业”，应看到成果列表、项目库入口，以及“人才库尚未开放／导师库尚未开放”。普通账号没有“双创运营工作台”；直接访问 `/innovation/reviews` 也应拒绝。
2. 点击“我的”。“本人双创管理”仅列“我的项目”和“负责人资料与资格”。校内浏览已移到主导航；原项目和资料页面地址仍可使用。
3. 在“我的”页面下滑到底，点击“退出登录”，再点击“确认退出登录”。“我的档案”和“个人信息”两个分区的最底端都只显示该按钮，省去额外标题和说明；学生顶栏用线条人像图标进入“我的”，不再显示退出按钮。确认后应回到登录页；后退或刷新受限页面需重新登录，同一浏览器配置中的另一个标签页也应失去原账号访问权限。**未保存输入不会保存**；退出确认页可取消，但开始退出后发生故障会保留重试入口。
4. 用 **20269002** 登录。应出现单独的“双创运营工作台”，可进入既有成果核实待办；进入运营页时“创新创业”不同时高亮。再退出，换回普通账号，运营入口应消失。
5. 缩窄到手机宽度。底部五栏为“首页／任务／创新创业／排行榜／我的”；上方“菜单”（可访问名称“全部导航”）可到积分奖励、通知，以及获授权账号的运营入口。菜单选择目的地后关闭，Escape 可关闭；页面不应横向溢出。

ACTIVE 教师和管理员也能从各自工作台的“创新创业”进入校内浏览，再通过“返回工作台”返回。教师、管理员身份不会自动获得学生双创运营授权。
