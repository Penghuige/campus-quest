## 约十分钟的验收流程

1. 用 **20269001** 打开“我的 → 我的项目草稿”，进入“【演示数据】校园循环利用项目”的“管理成果草稿”，打开“【演示数据】第一版原型”。上传示例 PDF；等待“文件检查通过”，勾选该证明，再点“提交首次核实”。预期显示“等待首次核实”，成果编辑被锁定，允许先撤回再修改。
2. 用 **20269003** 打开 `/innovation/achievements`。预期看不到这份待审成果。普通浏览者没有证明下载入口；知道私密文件直链也无法读取。
3. 用 **20269002** 打开 `/innovation/reviews`。领取该成果后才出现核实用负责人四项资料与证明。先填具体原因并“退回修改”。负责人重新读取后应看到原因，修改、保存后能重新提交。
4. 运营领取新的审核单并“通过首次核实”。普通浏览者现在能看到项目概况和成果内容；公开页面没有学号、负责人身份快照或证明材料。
5. 负责人修改并**只保存草稿**。普通浏览者刷新后仍看到上次已发布内容。负责人再点“发布更新（免复审）”；普通浏览者应看到新内容、首次核实日期、最近发布时间以及“更新内容未逐项复审”，运营待办中不会多出第二次审核。

键盘检查：用 Tab 移到提交按钮、Enter 打开确认框、Escape 取消；焦点应回到原按钮。手机宽度下主要表单和操作不应横向溢出。

## 可以反馈的具体问题

请记录“使用哪个账号、在哪一页、做了什么、期望与实际分别是什么”。出现错误时把页面给出的请求 ID 一并记下，便于定位；不需要把学号或证明原文发给其他人。
