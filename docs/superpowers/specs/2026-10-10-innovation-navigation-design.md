# R1 导航与退出登录设计

2026-10-10。用户已授权按 roadmap R1 制定计划并实施，不重复请求确认。依据：roadmap §2/4/5、需求 UI-02/UI-03（导航方向已由用户确认）、AC-01/02 的身份与资料边界；仓库 V1 §5.6/33/40 和前端设计系统。

## 范围与体验

- `/innovation` 为“创新创业”一级入口，成果优先，复用真实校内成果列表。项目库的当前可用范围是成果浏览；人才库、导师库文字说明尚未开放，不生成空路由或假操作；不显示第四库。
- `/innovation/achievements` 及详情保留旧 URL；学生浏览时保留学生导航。ACTIVE 的教师、管理员也能浏览，并可返回各自工作台。
- “我的”只放本人管理（负责人资料与资格、我的项目），移除公共浏览与运营身份面板。项目管理仍沿用私有草稿功能，不声称已扩成完整生命周期管理。
- `/innovation/reviews` 保留，命名“双创运营工作台”；仅 ACTIVE STUDENT 且服务端 `operations_enabled` 为真的账号显示主导航入口。资格申请与运营授权仍在 ADMIN 后台，菜单不替代后端鉴权。
- 桌面保留侧栏；中屏保留完整横向导航；手机仍为五栏（首页、任务、创新创业、排行榜、我的），奖励/通知/获授权运营通过顶部“全部导航”菜单可达。此 R1 产品变更覆盖旧五栏的固定内容合同，几何和触控标准不变。
- 账号区域和账户设置提供“退出登录”，进入独立 `/logout` 确认页。该页先卸载私密工作区，再由用户确认调用现有 `logout()`；成功用整页 `location.replace(应用前缀 + '/login')` 清除 Next Router 与内存中的旧账号页面。失败停留并明确“退出尚未确认”，可重试，绝不显示成功。注销请求及前置 refresh drain 最多等待 15 秒；drain 超时不抢先发送注销，后续重试仍等待原 refresh，保持 cookie 写入顺序。该端点精确 401 AUTHENTICATION_REQUIRED 表示没有 refresh credential，可结束退出。应用前缀独立于 API 前缀；学校 SSO 不在本轮。
- 本轮触及的审核确认框：取消仍恢复原按钮；异步成功导致原按钮消失/禁用时，焦点转到结果、重试操作或稳定队列标题。账号 epoch 变化后不得聚焦旧账号节点。

## 保留的决定与边界

已公开成果更新全部复审、旧通过版本保留属于 R2。本轮不改成果发布接口与状态机，也不宣称旧免复审实现符合新决定。招募独立免审但须负责人资格及项目权限，属于 R3。学校认证最后接入，预置演示账号与模拟资料必须标注。开发数据不重置；main 不修改；PR #43 保持 Draft，不合并。

## 2026-10-10 体验后的退出位置调整

用户明确要求“退出登录”放到“我的”页面下滑最底端，覆盖本设计先前的学生账号区域入口位置。学生顶栏移除退出链接；`/profile` 的“我的档案”和“个人信息”均在当前分区内容后提供同一退出区域，随文档滚动，不固定悬浮、不重复渲染。教师/管理员没有同一学生个人主页，原工作台退出入口保留。独立 `/logout` 确认、真实注销、错误重试、会话隔离与前缀处理保持原契约。

随后用户根据两张截图进一步明确：移除退出按钮前的可见“退出当前账号”标题与会话说明，仅保留底部按钮；学生顶栏“我的账户”入口改用项目现有 UserIcon 线条人像，替代昵称首字。链接目的地与可访问名称保留，侧栏的昵称展示保持原行为。

## 验收要求

三种屏宽可找到公共浏览、本人管理与授权运营；普通学生/教师不获得运营入口；直链越权被服务端拒绝。退出撤销真实会话、刷新受限页面不能读取校内资料；换账号和跨标签切换不留下前账号私密表单。退出失败可恢复且不假成功。键盘完成确认后焦点可继续操作。新增页进行 axe 与固定字体 Linux 截图；有意导航变化的旧基线独立提交并逐图说明，其他基线不变。
